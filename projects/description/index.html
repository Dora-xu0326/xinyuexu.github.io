Interaction Lab Reflection

Looking back at my projects so far, I noticed that I enjoy using colors, images, and typography to create different visual experiences. In Journal a Walk, I used photos, videos, and sounds to document my experience. In Recipe, I focused more on organizing information and making the steps easy to follow. For my Visual Only Website, I explored interaction by creating eight colorful strips that expand and reveal different ice creams when the user hovers over them. This project also made me realize that designing something in Figma is much easier for me than actually building it with HTML and CSS. I started to understand that even simple visual effects require a clear structure and an understanding of how different elements work together. Although my projects are different, they all reflect my interest in visual design and user experience. So far, I have learned more about HTML structure, CSS layouts, and interactions. Moving forward, I want to experiment with more creative interactions and improve my coding skills so I can bring my design ideas to life.
